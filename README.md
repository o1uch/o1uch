## Привет, я Павел 👋

Инженер эксплуатации и Go-разработчик.

Работаю с высоконагруженными телеком-системами, автоматизацией и сопровождением инфраструктуры. В последние годы активно развиваюсь в backend-разработке на Go и применяю опыт эксплуатации для создания надёжных и поддерживаемых сервисов.

Стек
- Языки: Go, SQL, Bash
- Базы данных: PostgreSQL, Oracle
- Инфраструктура: Linux, Docker, Git
- Мониторинг: Zabbix, Grafana

Немного обо мне:  

Пришел в разработку через задачи автоматизации: в процессе работы регулярно сталкивался с ограничениями Bash-скриптов, что привело к изучению Go и разработке внутренних инструментов для повышения надежности и удобства эксплуатации.  

Специализируюсь на автоматизации инфраструктуры, разработке сервисов на Go и оптимизации работы систем. Имею продакшен-опыт работы с Linux, SQL-базами данных, мониторингом и диагностикой инцидентов.  

В настоящее время продолжаю развивать навыки backend-разработки.
